# MSL Healthcare content inventory

Reviewed 19 November 2026 using public MSL pages and the client-supplied project brief. Source links below are research references. Website navigation uses local routes.

## Starting point

The workspace contained a Next.js App Router homepage with TypeScript, React, Tailwind CSS, a responsive header, static REC strip and CSS entrance effects. Inner route files, submission handlers and vacancy feeds were absent. The header and homepage constructed full MSL URLs for navigation and calls to action. Existing Yell policies were provider-hosted. Scroll-triggered reveals and complete candidate and client journeys needed implementation.
